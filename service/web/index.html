Этот сервер — мастер (главный)

Когда здесь смотрят уже столько человек, сколько указано, новых зрителей сервер перенаправляет (HTTP 302) на узел, где есть место. Кто уже смотрит — остаётся, где смотрел. На узлах нет мест — смотрит здесь.
Как настроить: на каждом подчинённом сервере (узле) откройте эту же вкладку и скопируйте его ключ из блока ниже → здесь «Добавить узел»: адрес узла, каким его видят зрители (например http://1.2.3.4:8090), и этот ключ → включите «Перенаправлять на узлы» → «Сохранить».
